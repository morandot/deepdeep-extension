# Deepdeep Browser Extension

BYOK AI chat browser extension with text selection popup and side panel chat.

## Install

### Chrome / Edge (Developer Mode)

1. Download `deepdeep-extension.zip` from [Releases](../../releases/latest)
2. Unzip the file
3. Open `edge://extensions` (or `chrome://extensions`)
4. Enable **Developer mode**
5. Click **Load unpacked** and select the unzipped folder

## Features

- Text selection popup (划词浮窗)
- Side panel chat with multi-conversation history
- Web search integration
- Vision/image analysis
- Multi-config profiles
- Export chat as Markdown
